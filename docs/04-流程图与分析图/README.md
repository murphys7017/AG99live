## 维护规则

1. 修改协议、播放所有权、动作编译或模型生命周期时，同步检查对应图源和正文。
2. 图源只描述当前实现与明确的运行边界；未实施能力写入专项设计或验收记录，不写入图集。
3. 不提交从 Mermaid 导出的 PNG、SVG 或 PDF 副本。
