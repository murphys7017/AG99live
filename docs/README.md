| 角色 | 入口文档 |

| **新开发者** | 项目总览 → 协议契约 → 动作链路 |
| **前端开发** | 项目总览 §4 → 动作链路 → ModelEngine 设计 |

## 维护规则

- 当前文档只写现在真实成立的结构和边界
- 当前文档里不保留“以前怎么样、现在改成怎么样”的叙述
- 仓库不维护历史文档树；过时文档直接删除或改写为当前状态
- 如果一个文档不再适合作为当前入口，就在当前文档体系内并表或删除
