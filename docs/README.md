# AG99live 文档

## 快速开始

新开发者推荐阅读顺序：

1. **[项目总览与模块职责](./01-架构与结构/01-项目总览与模块职责.md)** — 仓库结构、模块职责、依赖方向总览
2. **[WebSocket 协议契约](./01-架构与结构/02-WebSocket协议契约.md)** — 前后端通信协议
3. **[前后端动作链路结构](./01-架构与结构/03-前后端动作链路结构.md)** — Turn 播放从收到播的完整流程
4. **[播放同步编排设计](./01-架构与结构/04-播放同步编排设计.md)** — 原子段提交、文本/音频/动作同步起播和严格失败策略
5. **[端到端消息播放时序图](./01-架构与结构/05-端到端消息播放时序图.md)** — 从用户消息到后端响应再到前端播放与收口的流程图

动作能力相关的推荐继续阅读顺序：

1. **[ModelEngine 边界与分层设计](./02-设计文档/01-ModelEngine边界与分层设计.md)** — 前端动作编译边界、stage 规则、参数所有权
2. **[Motion 主轴/辅轴候选评估](./02-设计文档/06-Motion主轴辅轴候选评估.md)** — 轴为什么这样分组、哪些参数适合做主轴/辅轴
3. **[SpeechPoseStage 设计](./02-设计文档/04-SpeechPoseStage设计.md)** — 说话时随动的 compile 级增强规则
4. **[动作意图标签化与资源派生设计](./02-设计文档/10-动作意图标签化与资源派生设计.md)** — 当前动作生成链路权威规格；定义 Prompt 三层边界、九级入站契约、typed resource、系统派生字段和严格失败规则
5. **[动作处理链路修复与轴关系图设计](./02-设计文档/13-动作处理链路修复与轴关系图设计.md)** — 当前动作修复、轴关系图、九级强度实施状态，以及尚未完成的验收和可选增强
6. **[动作链路大更新实施总结](./02-设计文档/14-动作链路大更新实施总结.md)** — 九级动作、关系图、typed resource、统一 Timeline 和 Motion Lab 数据闭环的当前实施结果与剩余工作
7. **[表演曲线与语音同步设计](./02-设计文档/11-表演曲线与语音同步设计.md)** — 独立可配置 Provider 生成表演曲线提示，前端按真实音频时长求解 timing 的实施计划
8. **[统一时钟引擎改造设计](./02-设计文档/12-统一时钟引擎改造设计.md)** — 音频、动作、嘴型和表演曲线共享同一 segment timeline 的目标架构
9. **[前端结构维护清单](./02-设计文档/05-前端结构维护清单.md)** — 主控制器、适配器层、ModelEngine 与 Live2D runtime 的维护边界

播放和音频排障推荐阅读：

1. **[前后端动作链路结构](./01-架构与结构/03-前后端动作链路结构.md)** — 原子 `output.segment`、统一 Timeline 与三层完成语义
2. **[播放同步编排设计](./01-架构与结构/04-播放同步编排设计.md)** — `absent` 判定、原子段拒绝重复写入和本地播放完成条件
3. **[前端结构维护清单](./02-设计文档/05-前端结构维护清单.md)** — 播放链路、适配器静态资源和后端 turn 输出变更的验证命令

远程执行器和 Windows 操作能力推荐阅读：

1. **[远程执行器接入设计](./02-设计文档/07-远程执行器接入设计.md)** — Adapter、Codex app-server、Computer Use 和 Windows 操作委托边界
2. **[项目总览与模块职责](./01-架构与结构/01-项目总览与模块职责.md)** — 前端麦克风、PTT、远程执行器运行模块位置
