## 维护原则

- 文档只描述当前唯一设计和明确的产品边界。
- 已删除的协议、阶段性修复过程和测试结果不进入长期文档。
- 代码与文档冲突时，先沿真实调用链确认产品意图，再同步改正两者。
- 自动 smoke 只验证基础边界；实时 Electron 对话链路才是动作、音频和口型的最终验收。
- 流程图只维护 `.mmd` 源文件，不提交 PNG、SVG 或 PDF 副本。
