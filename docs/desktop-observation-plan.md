# AG99live 桌面变化观察计划

## 目标与边界
桌面采集、前后画面比较和模型配置由 AG99live 所有。复用 Electron 截图桥和 AstrBot RuntimeObservationSensor，不新增本体采样器、队列、冷却或主动发送路径。
0.8B 模型仅输出 changed 布尔值，不描述画面、不提取文字、不推断用户状态。MiniMax 主动决策沿用 Personal Policy 的模型配置。本阶段打通变化事实进入现有策略，不增加自动桌面内容分析或强制发言。

## 链路
插件生命周期启动观察服务 → 已连接且声明观察能力的桌面 → 独立 system 消息请求缩小后的截图 → 首帧建立基准 → 几何变化面积达到阈值 → 视觉 Provider 确认大范围变化 → 提交 desktop_changed → 现有收件箱/忙碌检查/策略决策 → Persona/语音/动作。
请求和结果以 request_id 关联，不创建聊天 Turn。截图不落盘、不进入普通历史，仅内存保留基准及当前帧。协议独立版本，只有匹配前端才采样。

## 默认参数与生命周期
默认关闭，Provider 显式配置，建议 ollama/qwen3.5:0.8b。采样默认30秒（最低10秒），模型超时15秒，事件有效期60秒。每个连接串行比较，不积压截图。无变化不发事件；变化事件带画面版本及合并键，避免相同材料重复制造新事实。
断连/连接替换、关闭、Provider变更、插件卸载取消任务并清除基准；重连首帧重新建立基准。截图/模型失败及非法返回不按有变化处理，不影响核心对话。配置保留中文说明。

## 实施与验收
1. 截图请求/结果协议及前端应答，复用截图桥并缩图。
2. AG99live观察模块、传感器注册、配置和生命周期接线。
3. 静态检查及最小协议成功/拒绝边界；本机模型用合成图片验收。
4. 配套加载后实测：首帧无事件、变化发事件、无变化安静、断连清理、对话不受影响，确认策略和Live输出日志。
真实 Electron/TTS/Live2D 验收须配套加载后执行。保留默认关闭；不自动重启，不进行整目录覆盖。


## 本轮实施结果
已实现前后端截图请求/结果协议、能力协商、内存两帧比较、传感器注册、任务取消和中文配置；本体未改。初版截图桥共享原生请求；当前已改为下述有截止时间的逻辑操作，支持超时恢复。截图最长边缩为768像素。

本机 Ollama 声明支持视觉；明显变化的合成图片经真实 AstrBot 原生 Provider 返回 true，热启动一次约362毫秒。直接把完全相同合成图交给模型时曾误报 true（约12.2秒）；采样/比较入口均对完全相同图片直接返回无变化。非相同图片上的误报率尚无真实桌面证据，不把该保护当作模型准确率保证。

前端类型检查及后端静态检查通过，插件结构检查无错误/警告。审阅补齐采样前的会话配置/会话禁用权限快照，并在连接会话身份变化时清除基准、丢弃旧结果。Electron 主进程、预加载与渲染端完整构建通过。已核对原始文件后，仅同步8个相关适配器文件到运行目录，保留其他修改；提交时跳过整目录部署钩子。尚未重启。加载配套前后端后，在插件设置中启用并选择视觉模型，读取 desktop_observation 与 Personal Policy 日志进行真实验收。MiniMax 的模型选择仍由本体主动策略配置负责。


## 2026-10-19 审阅修复与收敛

- 只检测大范围变化；新增变化面积百分比配置，默认15%。在192×108的RGB比较图上，单像素任一颜色通道差达到24/255才计入变化面积，抑制轻微JPEG噪声。低于面积门槛不调用模型；高于门槛仍由0.8B模型只返回布尔值。不做桌宠遮罩，允许漏掉小通知/弹窗；Windows通知另作事件源，本轮不接入。
- 共享截图改为共享有截止时间的逻辑操作。超时释放槽位；后台暂停自动重试，前台可尝试恢复，迟到图片不复用。原生IPC本身不能强制取消，避免把逻辑超时称作系统采集已取消。
- 适配器用本机单调时钟记录截图请求起点，所有采样、队列、几何比较和模型等待计入有效期。模型及提交仅获剩余预算，过期不发事件。
- 本体通用 Sensor 的公开 submit 接口保持不变，内部在调用入口固定绝对过期时间，避免权限检查等待后重新延长寿命。没有新增本体桌面专属逻辑。

验证：受控挂起截图的公开入口检查确认后台不堆积重试、前台恢复、迟到图丢弃。合成小范围变化0.59%被过滤、大范围63.02%通过15%门槛；真实原生Ollama Provider以新提示返回大变化 true（一次约540毫秒）。过期帧及含模拟准入等待的传感器过期时间检查通过；这是边界证据，不是真实桌面准确率或完整播放链路验收。

本次修复已审阅，未发现新的阻断问题；5个相关适配器文件已核对基线后选择性同步到运行目录，其他改动保留。提交跳过整目录部署钩子。尚未重启或进行真实桌面验收；需完整重启AstrBot，同时加载本体与适配器有效期修复及新版前端，不可只热重载插件。默认关闭保持不变。
