# AG99live 桌面变化观察计划

## 目标与边界
桌面采集与数学画面比较由 AG99live 所有。复用 Electron 截图桥和 AstrBot RuntimeObservationSensor，不新增本体采样器、队列、冷却或主动发送路径。
画面比较不调用模型、不提取文字、不分析具体内容或推断用户状态。是否主动说话仍由现有 Personal Policy 决定，策略模型继续使用本体配置。Windows 通知另作事件源，本轮不接入。

## 当前链路
插件生命周期启动观察服务 → 已连接且声明观察能力的桌面 → 独立 system 消息请求缩小后的截图 → 首帧建立基准 → 分块 SSIM 与颜色差估算变化面积 → 达到用户阈值 → 提交 desktop_changed → 现有收件箱/忙碌检查/安静时段/策略决策 → Persona/语音/动作。
请求与结果以 request_id 关联，不创建聊天 Turn。图片仅在内存中保留，不落盘、不进入普通历史、不发送给视觉模型。协议仍为 ag99live.desktop_observation.v1；本轮不改前端协议。

## 纯数学判断
- 将每帧缩放为192×108 RGB，划分为144个12×12区域。
- 每个区域按RGB通道计算均值、总体方差和协方差，计算分块SSIM，C1=(0.01×255)²、C2=(0.03×255)²。
- 区域的通道平均SSIM低于0.85，且平均绝对颜色差达到12/255，才计为变化区域；颜色差条件抑制低纹理区域的小噪声。
- 变化区域数/总区域数×100为面积估计，达到 changed_area_threshold_percent 才提交事实。这不是精确的变化像素比例；不分析变化是否值得搭话。
- 不做桌宠遮罩，允许漏掉小通知/弹窗及微动作。均匀亮度偏移可比原始像素差更稳定，但不保证所有亮度变化都会被忽略。

## 参数与生命周期
默认关闭，采样默认30秒（最低10秒），面积阈值默认15%（1～100），有效期默认60秒，对话后等待默认60秒（0～3600）。保留现有用户阈值，不自动改回50%；新旧算法的面积数值不能直接等同，需要真实桌面校准。
移除画面比较 provider_id、timeout_seconds 配置和模型解析路径。旧持久化配置即使残留这两个字段，也不再读取；不改用户的其他模型、安静时段或主动策略设置。
每个连接串行比较，不积压截图。断连/连接替换、关闭、采样参数变更、插件卸载取消任务并清除基准，重连首帧不发事件。比较在线程执行，完成后复核连接身份与有效期；失败不按变化处理。
共享截图有10秒逻辑截止，超时释放槽位、暂停后台自动重试，前台可恢复；迟到图不复用，原生IPC没有强制取消接口。
有效期从本机单调时钟的截图请求起点计算，覆盖采样、数学比对和提交等待；Core Sensor在提交入口固定过期时间。已入队事实遵循Core TTL，关闭采样不撤回。

## 对话优先与旧事件撤销
TurnCoordinator 维护连接级活动窗口，使用单调时钟。文字输入在准备前、PTT在音频处理前、VAD在实际语音开始时撤销旧窗口；不将持续静音PCM输入算作活动。输入准备、语音/STT、已提交/排队的事件、轮次处理及未完成播放均阻止采样。AI实际播放完成回执结束轮次后重新计算等待时间，空闲定义与鼠标键盘空闲无关。
窗口关闭时不请求新截图，清除旧基准；即使短对话发生在两次轮询之间，窗口信号/版本变化也会强制下次采样重新建立基准。采样前、截图返回后和数学比对后检查同一窗口。先前已发出的原生截图无法强制取消，迟到结果仅丢弃，不作为新基准。
Core通用Sensor submit增加可选 cancel_event（asyncio.Event），不进入模型payload。新输入设置旧信号，Inbox准入/取批/恢复时剔除失效来源；Policy与表达任务等待该信号，失效或到期取消工作，不再形成旧回复。普通未携带信号的来源沿用既有路径。混合批次保留其他未撤销事实，不用被撤销桌面事实的版本水位结清它们。新窗口即使出现相同图片版本，也可形成新的观察材料。
表达动作继承来源的撤销信号和期限，最终RuntimeObservationEvent在发送边界再次检查。已经发送到桌面端的片段不能追回；后续用户输入继续由既有打断链路处理。不新增前端协议、桌面专属Core Gate或并行主动会话系统。
必须完整重启AstrBot配套加载本体与适配器；本轮不改前端，不需要为此重新构建。安静时段仍由用户配置。
