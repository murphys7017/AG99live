# 端到端消息播放时序

## 正常路径

```mermaid
sequenceDiagram
    participant I as 输入窗口 / 麦克风 / 直播
    participant A as AG99
    participant P as Adapter
    participant S as SessionStore
    participant T as PlaybackTimeline
    participant M as ModelEngine
    participant L as Live2D
    participant C as CompletionCoordinator
    participant W as AdapterConnection

    I->>A: 提交输入
    A->>P: 平台输出、Core TTS、配置选定的动作结果
    P->>P: 以 message_id 聚合
    P-->>S: output.segment（schema: output.segment.v6, sequence）
    S->>T: 创建 SegmentJob
    T->>M: 给出段时钟和上下文
    M->>L: 开始参数计划或资源
    T->>T: 启动音频、字幕、口型
    opt 初始动作槽为 pending，且原段仍在播放
        P-->>S: output.segment_motion（相同 turn_id/message_id）
        S->>T: 补齐原段动作槽
        T->>M: 动作接入当前段时间线
    end
    L-->>T: 动作终态
    T-->>S: 段已结算
    S->>C: 本地段与 Turn 状态已稳定
    C->>W: 请求发送播放回执
    W-->>P: control.playback_finished
```

若提交完整文本/音频时动作仍在生成，Adapter 可在初始 `output.segment.v6` 中标记 `motion.state=pending`，并于同段仍播放时发送同身份的 `output.segment_motion`。它只完成原动作槽，不重复创建段、不重播音频；段结束后的迟到动作失败结算。

## 输入到 Turn

- 文本和直播弹幕直接建立正式 Turn。
- PTT 采集会话以松键结束；该会话的根 `turn_id` 可直接成为正式 Turn。
- 持续收音的根 `turn_id` 只代表采集会话。VAD 每检测到一段语音，会派生 `<capture_turn_id>:vad:<n>` 作为正式对话、输出和播放身份。
- 新语音开始时只中断同一采集根下仍在飞的 VAD 子 Turn，不停止持续采集本身。

## 段的顺序和完成

一个 Turn 可以包含多个逻辑消息。`message_id` 标识逻辑消息，`sequence` 给出该 Turn 内的播放顺序。动作来源只有 Persona Effect，或独立 Provider 对每个非空 Persona speech 段分别生成。普通 Persona 结果回调会按段启动动作任务；OLV 段流开启且 Core 能力检查通过时，各段动作请求在对应 speech 段到达后启动。TTS 身份到达后按段索引汇合，Core finalizer 等待动作准备，再由 Adapter 提交原子段。详见[动作生成与 Persona 分段关联](07-动作生成与Persona分段关联.md)。Adapter 在一条逻辑消息已完成时提交其段；`control.synth_finished` 只在后端不再有待发送段时到达。

前端把重复或晚到段当作协议拒绝，而不是重新打开已完成的播放。它完成一段时必须同时结束该段的媒体、动作运行和播放投影，再发送与该段一致的完成回执。

## 失败路径

| 位置 | 处理原则 |
| --- | --- |
| 入站解析 | 拒绝未知版本、非法 URL、重复或不完整 slot，不生成猜测数据。 |
| 动作编译 | 返回精确诊断；不以默认动作替代。 |
| 音频或运行时 | 结算所有已开启资源，保留真实失败状态。 |
| 中断 | 只清理目标 Turn 的运行；晚到输出不能重新进入播放。 |
| WebSocket 断开 | 后端请求停止在飞事件并清理映射；前端释放连接拥有的媒体、Timeline 和监听器。 |

## 透明输出时序

Live2D runtime 完成画布绘制后，桌面渲染进程才读取 RGBA 帧。主进程只接受宠物窗口发来的帧，并转交给 `AG99live.Live2D` Spout Sender。这样 OBS 获得的是 Live2D 图层而不是桌面合成结果。
