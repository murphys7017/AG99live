# 一期完成边界与二期入口

本文是 AG99live 产品阶段的唯一状态说明。README 只提供对外摘要，专项设计文档只描述当前实现或二期优化方向，不再各自定义“项目是否完成”。

## 1. 一期状态

**一期代码范围已经完成。**

这里的“完成”表示从用户输入到 Live2D 表演的正式链路已经具备明确协议、模块所有权和可运行实现。人工体验调校、真实设备观察和运行验收属于使用与调优过程，不作为未完成的实现债务写入项目状态。

## 2. 一期包含的能力

- AstrBot 对话、主模型回复、TTS 和 Persona Effect 接入。
- 主模型在同一次回复中生成 assistant text 与 `ag99live.motion`；官方 AstrBot 环境使用 `<@anim>` 传输同一份 V4 动作意图。
- `output.segment.v3` 原子输出段，以及 `turn_id + message_id + tts_request_id` 身份边界。
- SessionStore 与 PlaybackTimeline 分离协议事实和实时播放生命周期。
- `engine.motion_intent.v4` 到 `CompiledSemanticMotion`，再到 `engine.parameter_plan.v3` 的两阶段动作编译。
- 九级语义动作、确定性区间采样、语义轴关系图、模型参数绑定和显式响应策略。
- ParameterPresentation、ParameterMixer、口型、说话随动和 Cubism Physics 的逐帧执行边界。
- Profile Editor、Motion Lab、动作历史、系统设置和模型扫描。
- 文字、麦克风和 B 站直播弹幕输入，以及当前保留的可选远程操作委托。

## 3. 一期固定边界

- AstrBot 拥有对话、事件队列、主模型调用和 TTS；AG99live 不重复实现这些能力。
- Adapter 只负责 Prompt 能力投影、动作协议校验、身份关联和原子输出段交接，不生成 Live2D 最终参数。
- ModelEngine 负责语义动作编译和模型参数计划，不从文本重新决定主动作方向。
- PlaybackTimeline 是字幕、音频、动作和口型的统一播放时钟。
- ParameterMixer 只融合各模块已经生成的主动参数贡献，不成为第二套动作规划器。
- Live2D WebSDK 负责最终参数写入、口型信号、Cubism Physics 和渲染。
- 非法动作、身份冲突、时钟缺失或参数绑定失败必须显式失败，不使用默认动作或兼容路径掩盖问题。
- optional performance curve 可以失败、超时或被跳过，不能阻塞 TTS、segment 出站或基础动作播放。

## 4. 二期入口

以下内容用于提高动作质量、数据能力和部署成熟度，属于二期或更后阶段，不改变一期完成状态：

1. 参数时间轨道图：统一语义 sequence、phrase modulation、部位延迟、hold、release 和 residual。
2. 主动参数动力学深化：为 gaze、face、hesitation 和 residual 建立更细的响应策略。
3. Cubism Physics 诊断与模型级 profile：按 setting 分析输入、粒子链、输出和响应时间。
4. Motion Lab sequence 编辑、最近动作多样性反馈和更完整的数据筛选工作台。
5. 动作生成小模型训练，以及 VTube Studio 录制数据的语义标注和训练导出。
6. 远程操作能力拆分、跨主机安全部署和正式安装发布体验。
