# 小模型接入与动作训练数据计划

> 文档状态 设计与实施计划
> 适用基线 AG99live 1.0.0
> 目标 让小模型参与动作选择，同时保持本地组合和验证的确定性

## 1. 小模型的职责

小模型负责有限的选择问题：

- 当前状态适合哪个动作配方。
- 是否需要加入视线或呼吸变化。
- 组合动作的强度和节奏倾向。
- 是否暂时保持安静。

小模型不负责：

- 直接写入 Cubism 参数。
- 生成任意参数 ID。
- 生成未经验证的文件路径。
- 决定口型、眨眼和 Physics 的所有权。
- 管理 Turn、Playback 和播放终态。

## 2. 推荐输出

第一版使用高层配方选择：

```json
{
  "decision": "emit",
  "recipe_id": "quiet_thinking",
  "intent_tags": ["thinking", "uncertain"],
  "intensity": 0.42,
  "duration_hint_ms": 2200
}
```

如果需要更高的素材控制，可以增加经过 Adapter 校验的 `material_ids`。模型输出仍然不能越过素材目录和当前 Profile。

## 3. 请求时机

小模型请求只发生在以下时机：

- 进入新的长时间空闲区间。
- 进入思考或等待状态。
- 上一个素材组合动作完成后，候选需要更新。
- 当前场景标签发生稳定变化。

本地待机动作不等待小模型。每次请求都设置超时、结果 TTL 和冷却时间。

## 4. Prompt 内容

Prompt 只提供经过筛选的候选摘要：

- 配方 ID 和说明
- 可用域
- 强度范围
- 时长范围
- 适用状态
- 最近使用情况
- 当前环境状态摘要

Prompt 不提供完整参数曲线和本地文件路径。模型只在有限候选中做选择。

## 5. 训练数据边界

训练数据分成两类：

### 配方选择数据

输入当前表现状态和有限候选配方，输出配方 ID、标签和强度建议。该数据用于小模型的状态到配方选择。

### 参数动作数据

继续沿用现有 `motion_steps[].axis_values` 训练形态，用于正式动作意图生成。素材 ID 和配方选择不混入连续参数动作的监督目标。

组合器生成的动作可以记录为运行时诊断和人工评价样本。样本至少包含配方、素材、状态、最终动作计划和用户反馈。

## 6. 回退链路

```text
小模型选择成功
  → 校验配方和素材
  → 本地组合器生成计划

小模型超时或输出无效
  → 使用本地状态规则选择配方

组合器失败
  → 使用本地简单动作

本地动作不可用
  → 使用 Cubism 基础待机
```

回退只影响环境表现，不影响当前对话、TTS 和正式 Persona 动作。

## 7. 验收

- 小模型输出只能选择已注册的配方和素材。
- Provider 不可用时角色仍然保持基础生命感。
- 无效选择不会进入 ModelEngine。
- 小模型请求不会阻塞音频和正式对话动作。
- 训练样本能够区分配方选择和连续参数动作。
