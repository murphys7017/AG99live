# 动作素材组合与三层动作体系计划

> 文档状态 设计与实施计划
> 适用基线 AG99live 1.0.0
> 适用范围 TypeScript 运行时、AG99live Adapter 和 Live2D 动作资源
> 当前结论 已完成素材目录同步和纯 TypeScript 组合器基线，尚未接入环境动作调度

这组文档规划三类动作来源的统一实现：本地简单动作、基于扫描素材重新组合的动作、Persona 或大模型生成的动作。

三类动作共用动作意图、状态准入、参数编译和播放终态。素材扫描和组合策略属于 AG99live 的能力，AG99 负责语义请求和可选的配方选择，C++ 实现不在本计划范围内。
