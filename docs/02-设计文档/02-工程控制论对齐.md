# 工程控制论对齐

本项目保持 AI 代理治理最小化：观察、分类、评估风险、有界行动、校验、纠正。

## 映射

| 概念 | 运行时等价物 |
| --- | --- |
| 系统 | 仓库 + 代理 + `.ai/` |
| 控制器 | `AGENTS.md` 和 `.ai/index.md` |
| 状态 | `.ai/state.yaml` 和显式假设 |
| 传感器 | 文件检查、git 状态、测试、用户指令 |
| 反馈 | 审阅、校验、校验器输出 |
| 稳定性 | 有界范围、保留架构、可见的校验缺口 |
| 干扰 | 歧义、上下文丢失、工作区脏乱、校验失败、范围蔓延 |

## 循环

```text
任务 -> 分类 -> 风险 -> 检查 -> 变更 -> 审阅 -> 校验 -> 纠正/报告
```

低风险工作应保持轻量。高风险工作应使假设、状态、校验缺口和剩余风险显式化。
