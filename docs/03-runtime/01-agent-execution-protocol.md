# Agent Execution Protocol

Use `AGENTS.md` and `.ai/index.md`.

Loop:

1. Identify objective, success criteria, and non-goals when relevant.
2. Classify task and estimate risk.
3. Inspect relevant files.
4. Plan only when risk or complexity needs it.
5. Implement the smallest correct change.
6. Review, validate, correct, and report gaps.

State:

- Use `.ai/state.yaml` only when scope, risk, architecture impact, assumptions, or validation status should be explicit.
- Ask before recording persistent architecture decisions or project risks.

Completion:

- Objective satisfied or gap explicit.
- Validation status known.
- Residual risk visible.
- No required correction hidden.
